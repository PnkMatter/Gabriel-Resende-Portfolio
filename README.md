# Gabriel Resende — Portfolio

Personal portfolio of **Gabriel Resende, Data & AI Engineer**.

Live: https://pnkmatter.github.io/Gabriel-Resende-Portfolio/

## Stack

- React 18 + TypeScript
- Vite 6
- Tailwind CSS v4
- Motion (animations, respects `prefers-reduced-motion`)
- GitHub Actions → GitHub Pages

## Develop

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

Content lives in `src/data.ts`.
